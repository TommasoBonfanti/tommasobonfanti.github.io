Simulation, control software and electronics for a trapped-ion experiment

Research Assistant, Trapped Ion Quantum Information group, ETH Zurich · Jun. 2026 – Sep. 2026

Author
Tommaso Bonfanti
Supervision
Gabriele Giuli, Prof. Dr. Jonathan Home

Summary

Over three months as a research assistant in the Trapped Ion Quantum Information group, I worked across the experiment: from numerical simulation of the physics, to the software that runs the experiment, to the electronics that read it out.

Simulation

I extended a QuTiP-based spin-squeezing simulation module to support time-dependent Hamiltonians and inhomogeneous couplings, with Monte Carlo sampling of Brownian phase noise.

Control software

The setup is moving to a new control system, in which experiments are written in Python with the group’s PyCrystal library and run on an RFSoC-based controller. I built the new Experiment Library for the setup from the ground up, porting, reorganising and extending the experiments from the legacy C++ code: from the hardware description and a common cool–manipulate–detect frame to carrier, sideband and sideband-cooling sequences. I also helped install the new hardware, mount it in a new rack and plan the cabling.

Electronics

I designed in KiCad, assembled and bench-tested a 4-layer PCB that converts the EMCCD camera’s LVDS readout signal to 3.3 V TTL at 40 MHz.
